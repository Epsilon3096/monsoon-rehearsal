# Draft intake templates

Every `synthetic_*` file is an invented software fixture. No site, operator, approval, sensor calibration or physical experiment is represented. Dates in the JSON examples are fictional metadata.

- `synthetic_site_v1.json` is a valid three-node site-data staging example. It cannot activate the synthetic SWMM model or dispatch a ticket.
- `synthetic_source_evidence.txt` is the actual fixture text referenced by the sample source hash.
- `synthetic_measurements_v1.json` binds the sample site hash and exercises uneven-interval arithmetic. Its identical observations/predictions are intentional and are not physical proof.
- `bench_protocol_v1.json` freezes prospective project thresholds and event assignments before measurements. Its pinned identity is checked by the measurement module. It remains pending laboratory/operator review.

Read `../../SITE_DATA_CONTRACT.md` and `../../PHYSICAL_VALIDATION.md` for semantics, required evidence and limits. A complete upload is review material, never an assertion of field readiness.
